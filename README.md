# 观照 · 多视角调研

一个围绕AI项目与软件方案比较的中文调研原型：先按认知视角检查器理解目标、约束与双方预设，再调用搜索和正文读取工具，整理网页出处、资料参考价值及限制，给出条件判断。

## 部署

Render选择Web Service / Python / Free，构建 `pip install .`，启动 `python -m app.cloud_main`，健康检查 `/health`。平台提供HTTPS访问地址，无需购买域名。完整配置见render.yaml与docs/Render免费部署.md。

密钥只配置在服务端环境变量。GUANZHAO_ONLINE_UNTIL为空或过期时，真实模型/搜索请求关闭；先验证网页访问，再由维护者设置已授权的固定开放时间。不要提交.env、数据库或私人调研记录。

## 当前状态

0.3.0曾在百炼部署并通过健康/配置检查，唯一真实案例在搜索上限处理处中断。0.3.1已离线修复，58项模拟检查通过；修复版真实端到端结果待验证。没有已证明的节省时间或认知改善效果。

访客通过签名Cookie隔离记录。同一数据库全站3任务、每位访客1任务；每任务模型6/搜索2/正文3请求上限，含失败重试。临时磁盘回收会清空记录和计数，不能把这些次数当成长期金额硬上限。持续开放前需补持久存储和累计额度。

## 依赖与验证

Python>=3.11。使用 `pip install .` 安装运行依赖。模拟检查可安装pytest后运行 `python -m pytest -q`，不请求真实模型或搜索服务。来源片段匹配检查不能替代人工判断事实是否被引用支持。

本项目尚未确定整体开源许可证；目前作为可公开查看的原型源码准备。附带认知视角检查器Skill的许可证信息保留在其文件中。
